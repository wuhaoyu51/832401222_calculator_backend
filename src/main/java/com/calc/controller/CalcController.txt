# 832401222_calculatorfrontend
前后端分离计算器 - 前端Web页面

## 项目介绍
原生HTML+JavaScript实现计算器前端页面，负责接收用户输入表达式，调用后端API发送计算请求，展示后端返回结果。
同时可以从后端数据库读取计算历史记录，支持删除指定历史记录。
前端**不执行任何数学计算**，全部计算逻辑交由后端完成。

## 技术栈
- HTML5
- JavaScript (ES6)
- CSS

## 使用方法
1. 将calc.html放在静态网页服务中打开（VSCode Live Server / Github Pages）
2. 修改代码中 `baseUrl`，替换为后端公网/本地接口地址（如`http://127.0.0.1:8080/api`）
3. 在输入框输入数学表达式，点击【计算】获取结果
4. 页面加载自动拉取后端历史记录，可点击删除按钮删除单条记录

## 功能清单
1. 基础四则运算：`+ - * /`
2. 复合表达式，支持括号、负数、小数，例如 `(10-2)*3`、`-5+3.5`
3. 接收后端异常提示，展示错误信息
4. 从后端数据库读取历史记录并渲染页面
5. 根据记录ID向后端发送删除请求，删除成功后刷新历史列表
